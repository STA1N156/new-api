## 保存与到账

`baking_accounts` 保存累计到账和原料消耗，`baking_contributions` 保存唯一充值来源，`baking_rounds` 保存每炉状态。应用启动时自动建表，兼容现有三种数据库。

到账记录与支付/兑换在同一个事务内保存，来源唯一键防止重复累计。动作先锁用户，再验证当前炉次与版本；同一原料不能重复使用，同一奖励不能重复到账。服务器使用加密随机数分别判定结果和2～4秒的烘焙等待时间，两者互不影响。等待期间不返回结果；刷新、断线不会重新抽取或重新计时。

奖励的额度换算在开炉时固定，领取使用现有余额入账及缓存同步。前端在领取动画结束后更新累计领取数字。没有新增依赖或后台定时任务。
