# 易支付分渠道配置

系统设置 → 计费 → 支付网关 → Epay，可分别配置支付宝和微信的平台地址、商户 ID、密钥。余额充值和订阅购买使用同一套分渠道规则。

- 支付宝使用 `EpayAlipayAddress`、`EpayAlipayId`、`EpayAlipayKey`；微信使用 `EpayWxpayAddress`、`EpayWxpayId`、`EpayWxpayKey`。
- 独立地址留空时，沿用原来的 `PayAddress`、`EpayId`、`EpayKey` 默认平台。填写独立地址后，必须使用该渠道完整的凭证，不与默认平台拼接。
- 密钥不通过设置查询接口返回；表单密钥留空保存时保留原密钥。两个平台共用站点回调地址，无需修改回调路由。
- 充值订单和订阅订单保存 `epay_gateway`。回调从订单选择平台，校验签名、商户、订单号、独立渠道类型和支付金额，再执行原有幂等结算。旧订单的空标记始终使用默认平台。
- 未配置完整的方式不会在钱包显示。平台变更或密钥轮换仍需保留未完成订单所需的原配置，渠道标记不会保存历史密钥。
